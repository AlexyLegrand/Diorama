# Audio

The game uses two music tracks (below). The other tables list the sound effects still to make:
drop the `.mp3` files in the matching folder using these names.

## Music (looping, in world/)

| File | When |
|---|---|
| `world/diorama_ambiance.wav` | Title and settings screens |
| `world/diorama_ambiance_version_longue.wav` | Everywhere after the title menu (world map and levels) |

## player/ — Sprout animations

| File | Animation |
|---|---|
| `step_1.mp3` … `step_4.mp3` | `Walk` (footsteps, picked at random) |
| `climb.mp3` | `Climb` (ladder) |
| `push_start.mp3` | `PushStart` |
| `push.mp3` | `Push` |
| `crank.mp3` | `Crank` (effort) |
| `victory.mp3` | `Victory` (cheer) |
| `bump.mp3` | Move blocked (wall, stuck crate) |

## world/ — objects and ambience

| File | Source |
|---|---|
| `crate_slide.mp3` | Crate sliding |
| `crate_land.mp3` | Crate stops |
| `crank_turn.mp3` | Crank gear (`Turn`) |
| `platform_move.mp3` | Platform moving |
| `platform_stop.mp3` | Platform arrives |
| `seed_idle.mp3` | Golden seed shimmer (loop) |
| `seed_collect.mp3` | Golden seed collected (`Collect`) |
| `ambience_wind.mp3` | Wind and foliage (loop) |
| `bird.mp3` | Bird flaps / chirps |

## ui/ — menus and transitions

| File | Event |
|---|---|
| `move.mp3` | Menu selection changes |
| `confirm.mp3` | Confirm |
| `back.mp3` | Back (Escape) |
| `volume.mp3` | Volume changed |
| `key_bound.mp3` | Key rebound |
| `entrance.mp3` | Standing on a level entrance |
| `locked.mp3` | Locked level |
| `transition.mp3` | Entering / leaving a level |
| `restart.mp3` | Level restarted |
| `unlock.mp3` | New level unlocked |
